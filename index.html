FAQ

Questions before you download

The most common things players ask about the FS25 Farming Mod Menu.

Is the FS25 Farming Mod Menu free to use?
Yes. The mod menu is free and open source. You can download it from the release page, use it on any of your own saves, and inspect or modify the Lua source if you want to tweak multipliers or add your own shortcuts.
Will this work in multiplayer or on dedicated servers?
The mod menu is designed for single-player and local saves. Multiplayer and dedicated servers run server-side validation, so money and XP changes may not sync, and using it on public servers can violate their rules. Keep it to your own farm.
Does it break my save game or existing mods?
It loads as a standard FS25 mod and does not overwrite vanilla files. Money and XP changes are written to the save like normal gameplay values. As always, back up your save folder before enabling any new mod, and disable the menu if you notice conflicts with other script mods.
Which game version and platform are supported?
The current release targets Farming Simulator 25 on Windows 10 and Windows 11 with the latest game patch. Version v2.4.1 includes fixes for the vehicle spawner and field auto-work toggles. Check the changelog on the download page before updating an older install.
